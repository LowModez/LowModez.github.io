Software / C++

Password Generator

planned

A small command line tool that builds a password to a requested length from a chosen set of character groups. The point of it is the parts a beginner exercise usually skips: generating from the standard library's random facilities rather than rand(), validating arguments before using them, and guaranteeing at least one character from every group the user asked for.

  • C++
  • Standard Library
  • CLI Arguments
  • Input Validation

Software / Python

File Organizer

planned

A script that sorts a cluttered folder into subfolders by file type, written to solve an actual annoyance rather than an exercise. It runs in preview mode by default so it prints what it would move before it moves anything, handles name collisions instead of overwriting, and logs every action it takes.

  • Python
  • pathlib
  • argparse
  • Automation

Networking / Python

Subnet Calculator

planned

Takes an address in CIDR notation and prints the network address, the broadcast address, the usable host range, the subnet mask, and the number of hosts. It is a small program, but it sits exactly where my two backgrounds meet: it is the arithmetic I already do by hand on a job, written down as code.

  • Python
  • ipaddress
