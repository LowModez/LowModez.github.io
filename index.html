01 / About

About

I'm a Computer Science student at Full Sail University, working toward a Bachelor of Science with a concentration in Artificial Intelligence. My background is in Information Technology — I completed an Associate of Science in IT before moving into Computer Science.

That IT foundation covered the practical side of systems: Windows and Windows Server, networking, virtualization, Active Directory, hardware, and troubleshooting. I've also built out a home lab with Proxmox to practice those concepts in an environment I can break and rebuild.

My experience isn't only academic. I've done hands-on work with physical infrastructure and commercial security systems — structured cabling, PoE networking, IP cameras and NVR systems, access control, and alarm systems — along with the work that surrounds an install: planning, equipment configuration, network troubleshooting, documentation, and explaining the result to customers in plain language.

Now the focus is software. I work mostly in C++, and my current project, Heartfire, is a terminal-based dungeon crawler I'm using to practice multi-file program structure, classes, and game state rather than one-off exercises. I'm looking for software development, IT, and technical support work where both halves of that background are useful.

Heartfire

in-development

A terminal-based dark fantasy dungeon crawler built to practice multi-file program structure, classes, and game state in C++.
