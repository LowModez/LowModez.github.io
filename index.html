01 / About

About

I'm a Computer Science student at Full Sail University, working toward an Associate of Science in Computer Science, with the bachelor's and its Artificial Intelligence concentration to follow. My background is in Information Technology: I completed an Associate of Science in IT before moving into Computer Science.

That IT foundation covered the practical side of systems: Windows and Windows Server, networking, virtualization, Active Directory, hardware, and troubleshooting. I've also built out a home lab with Proxmox to practice those concepts in an environment I can break and rebuild.

My experience isn't only academic. I've done hands-on work with physical infrastructure and commercial security systems, including structured cabling, PoE networking, IP cameras and NVR systems, access control, and alarm systems. That covered the work surrounding an install too: planning, equipment configuration, network troubleshooting, documentation, and explaining the result to customers in plain language.

Now the focus is software. I work mostly in C++, and my current project, Heartfire, is a terminal-based dungeon crawler I'm using to practice multi-file program structure, classes, and game state rather than one-off exercises. I'm looking for software development, IT, and technical support work where both halves of that background are useful.

Web / Front-End

This Portfolio Site

live

Hand-written HTML and CSS with no framework, no build step, and no dependencies, deployed on GitHub Pages. The layout is CSS Grid and Flexbox, every color and size comes from custom properties in one tokens file, and the small amount of JavaScript is limited to the things CSS cannot do. Software / C++

Password Generator

planned

A small command line tool that builds a password to a requested length from a chosen set of character groups. The point of it is the parts a beginner exercise usually skips: generating from the standard library's random facilities rather than rand(), validating arguments before using them, and guaranteeing at least one character from every group the user asked for.

  • C++
  • Standard Library
  • CLI Arguments
  • Input Validation

Software / Python

File Organizer

planned

A script that sorts a cluttered folder into subfolders by file type, written to solve an actual annoyance rather than an exercise. It runs in preview mode by default so it prints what it would move before it moves anything, handles name collisions instead of overwriting, and logs every action it takes.
